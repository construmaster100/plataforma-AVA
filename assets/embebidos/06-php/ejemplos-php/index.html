Ejemplos básicos de PHP

Seis piezas de código comentadas, con la salida que producen. Ábrelas, léelas y repítelas antes de pasar a la actividad.

1. Variables y salida Fundamentos

Las variables llevan dólar y las cadenas interpolan dentro de comillas dobles.

<?php
$ficha = "3293836";
$aprendices = 27;

echo "Ficha $ficha con $aprendices aprendices";
Ficha 3293836 con 27 aprendices
2. Condicionales Control

La sintaxis de llaves es la misma de C y Java.

<?php
$nota = 3.8;

if ($nota >= 4.0) {
    echo "Excelente";
} elseif ($nota >= 3.0) {
    echo "Aprobado";
} else {
    echo "Debe reforzar";
}
Aprobado
3. Arreglos Estructuras

El arreglo puede ser indexado o asociativo.

<?php
$notas = [4.5, 3.8, 4.9];
$aprendiz = ["nombre" => "Sara", "ficha" => 3293836];

echo count($notas) . " · " . $aprendiz["nombre"];
3 · Sara
4. Ciclos Control

foreach recorre pares clave–valor sin llevar índice a mano.

<?php
$fases = ["Análisis", "Planeación"];

foreach ($fases as $i => $fase) {
    echo ($i + 1) . ". $fase\n";
}
1. Análisis
2. Planeación
5. Funciones Modularidad

Se pueden declarar los tipos de los parámetros y del retorno.

<?php
function promedio(array $valores): float {
    if (!$valores) return 0;
    return array_sum($valores) / count($valores);
}

echo promedio([4.5, 3.8, 4.9]);
4.4
6. Formulario y servidor Web

Nunca se confía en lo que llega: se valida y se escapa.

<?php
$nombre = trim($_POST["nombre"] ?? "");

if ($nombre === "") {
    http_response_code(400);
    exit("Falta el nombre");
}

echo "Hola " . htmlspecialchars($nombre);
Con nombre vacío responde 400; si llega, saluda con el texto escapado.
