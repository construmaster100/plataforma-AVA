2. Variables e interpolación Fundamentos

El dólar delante de la cadena permite incrustar expresiones.

string ficha = "3293836";
int aprendices = 27;
double promedio = 4.5;

Console.WriteLine($"Ficha {ficha}: {aprendices} aprendices, {promedio:F1}");
Ficha 3293836: 27 aprendices, 4.5
3. Colecciones Estructuras

List<T> es la colección de uso diario.

using System.Collections.Generic;

var notas = new List<double> { 4.5, 3.8 };
notas.Add(4.9);

Console.WriteLine(notas.Count);
3
4. Clases y propiedades Objetos

La propiedad encapsula el dato sin escribir get y set a mano.

class Aprendiz {
    public string Nombre { get; set; }
    public double Nota { get; set; }

    public bool Aprobo() => Nota >= 3.0;
}

var a = new Aprendiz { Nombre = "Sara", Nota = 3.8 };
Console.WriteLine(a.Aprobo());
True
5. LINQ Consultas

Where filtra y Select proyecta, sin escribir el ciclo.

using System.Linq;

var notas = new[] { 4.5, 2.8, 3.9 };
var aprobadas = notas.Where(n => n >= 3.0).ToList();

Console.WriteLine($"{aprobadas.Count} de {notas.Length} · promedio {notas.Average():F2}");
2 de 3 · promedio 3.73
6. Excepciones Robustez

finally se ejecuta pase lo que pase.

try {
    int[] datos = new int[2];
    Console.WriteLine(datos[5]);
} catch (IndexOutOfRangeException e) {
    Console.WriteLine("Índice fuera de rango");
} finally {
    Console.WriteLine("Fin");
}
Índice fuera de rango
