Ejemplos básicos de Desarrollo web

Seis piezas de código comentadas, con la salida que producen. Ábrelas, léelas y repítelas antes de pasar a la actividad.

1. Las tres capas Arquitectura

Estructura, presentación y comportamiento se separan a propósito.

<!-- estructura -->
<button id="saludo">Saludar</button>

/* presentación */
#saludo { background: #007832; color: #fff; }

// comportamiento
document.getElementById("saludo")
  .addEventListener("click", () => alert("Hola"));
Al pulsar el botón verde aparece el aviso «Hola».
2. Manipular el DOM Cliente

querySelector busca en el árbol; textContent cambia el texto.

const titulo = document.querySelector("h1");
titulo.textContent = "Ficha 3293836";
titulo.classList.add("activo");
El primer h1 pasa a decir «Ficha 3293836» y gana la clase activo.
3. Petición a una API Cliente–servidor

fetch devuelve una promesa; await espera la respuesta.

async function cargarFicha() {
  const r = await fetch("/api/fichas/3293836");
  if (!r.ok) throw new Error("Error " + r.status);
  const datos = await r.json();
  console.log(datos.aprendices);
}
Imprime el número de aprendices, o lanza «Error 404» si no existe.
4. Formulario y validación Interacción

preventDefault evita que el navegador recargue la página.

formulario.addEventListener("submit", e => {
  e.preventDefault();
  if (!correo.value.includes("@")) {
    aviso.textContent = "Correo inválido";
    return;
  }
  enviar();
});
Sin arroba muestra «Correo inválido» y no envía.
5. Almacenamiento local Cliente

localStorage guarda texto en el navegador entre visitas.

localStorage.setItem("tema", "oscuro");
const tema = localStorage.getItem("tema");
console.log(tema);
oscuro
6. Respuesta del servidor Servidor

El estado y el tipo de contenido le dicen al cliente qué recibió.

HTTP/1.1 200 OK
Content-Type: application/json

{ "ficha": "3293836", "aprendices": 27 }
El cliente convierte ese JSON en un objeto con r.json().
