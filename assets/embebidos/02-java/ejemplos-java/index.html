Ejemplos básicos de Java

Seis piezas de código comentadas. Java es de tipado estático: cada variable declara su tipo y el bloque se delimita con llaves.

1. Estructura mínima y variables Fundamentos

Todo programa vive dentro de una clase y arranca en main.

public class Ficha {
    public static void main(String[] args) {
        String nombre = "Ficha 3293836";
        int aprendices = 27;
        double promedio = 4.5;
        boolean activa = true;

        System.out.println(nombre + " " + aprendices);
        System.out.println(promedio + " " + activa);
    }
}
Ficha 3293836 27
4.5 true
2. Entrada por teclado Fundamentos

Scanner lee de la consola; hay que importarlo y cerrarlo.

import java.util.Scanner;

public class Edad {
    public static void main(String[] args) {
        Scanner lector = new Scanner(System.in);
        System.out.print("¿Cuántos años tiene? ");
        int edad = lector.nextInt();
        System.out.println("El próximo año tendrá " + (edad + 1));
        lector.close();
    }
}
¿Cuántos años tiene? 19
El próximo año tendrá 20
3. Condicionales Control

Las llaves delimitan el bloque y la condición va entre paréntesis.

double nota = 3.8;

if (nota >= 4.0) {
    System.out.println("Excelente");
} else if (nota >= 3.0) {
    System.out.println("Aprobado");
} else {
    System.out.println("Debe reforzar");
}
Aprobado
4. Ciclos Control

El for clásico lleva inicio, condición y paso; el for-each recorre colecciones.

for (int i = 1; i < 4; i++) {
    System.out.println("Vuelta " + i);
}

String[] fases = {"Análisis", "Planeación", "Ejecución"};
for (String fase : fases) {
    System.out.println("Fase: " + fase);
}

5. Arreglos y listas Estructuras

El arreglo tiene tamaño fijo; ArrayList crece.

import java.util.ArrayList;

double[] notas = {4.5, 3.8, 4.9};
System.out.println(notas[0] + " " + notas.length);

ArrayList<String> ficha = new ArrayList<>();
ficha.add("Sara Valentina");
ficha.add("Kevin Sair");
System.out.println(ficha.get(0) + " · " + ficha.size());

Sara Valentina · 2
6. Métodos y clases Modularidad

Un método declara el tipo que devuelve; void significa que no devuelve nada.

public class Calculadora {

    public static double promedio(double[] valores) {
        if (valores.length == 0) return 0;
        double suma = 0;
        for (double valor : valores) suma += valor;
        return suma / valores.length;
    }

    public static void main(String[] args) {
        System.out.println(promedio(new double[]{4.5, 3.8, 4.9}));
    }
}
4.4
