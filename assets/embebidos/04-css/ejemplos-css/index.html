Ejemplos básicos de CSS

Seis piezas de código comentadas, con la salida que producen. Ábrelas, léelas y repítelas antes de pasar a la actividad.

1. Cómo se enlaza Fundamentos

La hoja externa se enlaza desde el head y sirve para todo el sitio.

<!-- en el HTML -->
<link rel="stylesheet" href="estilos.css">

/* en estilos.css */
body { font-family: system-ui; }
Toda la página adopta la tipografía del sistema.
2. Selectores Fundamentos

Etiqueta, clase e identificador, de menor a mayor peso.

p        { color: #444; }
.destaca { color: #007832; }
#titulo  { font-size: 24px; }
Si un párrafo tiene class="destaca", gana el verde sobre el gris.
3. Modelo de caja Maquetación

box-sizing: border-box evita que el relleno agrande la caja.

.tarjeta {
  box-sizing: border-box;
  width: 300px;
  padding: 16px;
  border: 1px solid #ddd;
  margin-bottom: 12px;
}
La tarjeta mide 300px en total, no 332px.
4. Flexbox Maquetación

Una fila que reparte el espacio y se centra en vertical.

.barra {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}
Los hijos quedan en fila, separados a los extremos y centrados.
5. Rejilla Maquetación

auto-fill llena las columnas que quepan sin desbordar.

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}
Cuatro columnas en pantalla ancha, una en el móvil.
6. Responsive Adaptación

La consulta de medios cambia la maquetación al estrecharse.

.panel { display: flex; }

@media (max-width: 700px) {
  .panel { display: block; }
}
En el móvil los bloques se apilan en lugar de ir en fila.
