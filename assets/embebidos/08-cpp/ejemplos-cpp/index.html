Ejemplos básicos de C++

Seis piezas de código comentadas, con la salida que producen. Ábrelas, léelas y repítelas antes de pasar a la actividad.

1. Programa mínimo Fundamentos

iostream y el operador de inserción sustituyen a printf.

#include <iostream>
using namespace std;

int main() {
    cout << "Ficha 3293836" << endl;
    return 0;
}
Ficha 3293836
2. Entrada y cadenas Fundamentos

string es una clase: conoce su tamaño y gestiona su memoria.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string nombre;
    cout << "Nombre: ";
    getline(cin, nombre);
    cout << "Hola " << nombre << " (" << nombre.size() << ")";
}
Nombre: Sara → Hola Sara (4)
3. Vectores Estructuras

El vector crece solo y sabe cuántos elementos tiene.

#include <vector>

vector<double> notas{4.5, 3.8};
notas.push_back(4.9);

double suma = 0;
for (double n : notas) suma += n;

cout << suma / notas.size();
4.4
4. Clases Objetos

Los datos privados se tocan solo por métodos públicos.

class Aprendiz {
private:
    string nombre;
    double nota;
public:
    Aprendiz(string n, double p) : nombre(n), nota(p) {}
    bool aprobo() const { return nota >= 3.0; }
    string getNombre() const { return nombre; }
};
Aprendiz a("Sara", 3.8); a.aprobo() devuelve true.
5. Referencias y punteros Memoria

La referencia es un alias; el puntero puede ser nulo y reasignarse.

int x = 10;
int &alias = x;
int *puntero = &x;

alias = 20;
cout << x << " " << *puntero;
20 20
6. Plantillas Genéricos

Una sola función sirve para cualquier tipo comparable.

template <typename T>
T mayor(T a, T b) {
    return a > b ? a : b;
}

cout << mayor(4, 9) << " " << mayor(2.5, 1.5);
9 2.5
