1. Programa mínimo Fundamentos

Se incluye la cabecera, se declara main y se devuelve 0.

int main(void) {
    printf("Ficha 3293836\n");

}

2. Variables y formato Fundamentos

Cada tipo tiene su especificador al imprimir.

#include <stdio.h>

int main(void) {
    int aprendices = 27;
    double promedio = 4.5;
    char inicial = 'A';

    printf("%d %.1f %c\n", aprendices, promedio, inicial);
    return 0;
}
27 4.5 A

4. Arreglos Estructuras

El arreglo no conoce su tamaño: hay que llevarlo aparte.

double notas[3] = {4.5, 3.8, 4.9};
double suma = 0;

for (int i = 0; i < 3; i++) {
    suma += notas[i];
}

printf("%.2f\n", suma / 3);
4.40
5. Punteros Memoria

El puntero guarda una dirección; el asterisco lee su contenido.

int x = 10;
int *p = &x;

printf("%d\n", *p);
*p = 20;
printf("%d\n", x);
10
20
6. Funciones Modularidad

Se declara el tipo devuelto y el de cada parámetro.

#include <stdio.h>

double promedio(double v[], int n) {
    if (n == 0) return 0;
    double s = 0;
    for (int i = 0; i < n; i++) s += v[i];
    return s / n;
}

int main(void) {
    double notas[] = {4.5, 3.8, 4.9};
    printf("%.2f\n", promedio(notas, 3));
    return 0;
}
4.40
