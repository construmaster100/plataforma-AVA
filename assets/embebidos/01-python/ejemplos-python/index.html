Ejemplos básicos de Python

Seis piezas de código comentadas. Ábrelas, léelas y repítelas en la consola antes de pasar a la actividad.

1. Variables y tipos Fundamentos

Una variable guarda un valor y no se declara con tipo: Python lo deduce.

nombre = "Ficha 3293836"   # str
aprendices = 27            # int
promedio = 4.5             # float
activa = True              # bool

print(nombre, aprendices, promedio, activa)
print(type(promedio))
Ficha 3293836 27 4.5 True
<class 'float'>
2. Entrada y salida Fundamentos

input siempre devuelve texto: si se necesita un número hay que convertirlo.

edad = int(input("¿Cuántos años tiene? "))
print("El próximo año tendrá", edad + 1)
¿Cuántos años tiene? 19
El próximo año tendrá 20
3. Condicionales Control

El bloque se delimita con la sangría, no con llaves.

nota = 3.8

if nota >= 4.0:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobado")
else:
    print("Debe reforzar")
Aprobado
4. Ciclos Control

for recorre cualquier colección; range genera una secuencia de números.

for i in range(1, 4):
    print("Vuelta", i)

fases = ["Análisis", "Planeación", "Ejecución"]
for fase in fases:
    print("Fase:", fase)
Vuelta 1
Vuelta 2
Vuelta 3
Fase: Análisis
Fase: Planeación
Fase: Ejecución
5. Listas y diccionarios Estructuras

La lista es ordenada y se indexa desde cero; el diccionario guarda pares clave–valor.

notas = [4.5, 3.8, 4.9]
notas.append(3.2)
print(notas[0], len(notas), sum(notas) / len(notas))

aprendiz = {"nombre": "Sara Valentina", "ficha": 3293836}
print(aprendiz["nombre"])
4.5 4 4.1
Sara Valentina
6. Funciones Modularidad

Una función agrupa un cálculo con nombre y puede devolver un resultado.

def promedio(valores):
    """Devuelve el promedio de una lista de notas."""
    if not valores:
        return 0
    return sum(valores) / len(valores)

print(promedio([4.5, 3.8, 4.9]))
print(promedio([]))
4.4
0
